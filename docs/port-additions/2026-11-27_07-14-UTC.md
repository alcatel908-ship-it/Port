## Quarantined exact buffers

`VICTORY_EXACT_QUARANTINE=1` selects the independent new cache and pool for exact views. It takes shared read locks on hits, allocates outside map lock, prunes idle views, gates recycling on frame lag AND submission completion, and drains ready buffers under pressure. Default off. `VICTORY_EXACT_POOL_MB` controls the new pool (donor defaults 256 MiB limited RAM, otherwise 320 MiB; 0 disables recycling but keeps new cache). The original view and upload pools remain available; use the original pool flags off when testing the alternative to isolate memory and lifetime behavior.

Local modifications: take production retirement watermarks after eviction, read queued count before started count (matching host retire order), require Arc::try_unwrap and sole COM reference at eviction, recheck COM reference at take, clear entire recycled bucket (conservative, additional CPU cost), adjust descriptor width test for selected mode. Unknown GPU access and submission lifetime still require hardware review. Donor reports 402 passing GPU tests on RTX 3060, not tested in title; these numbers are NOT Port tests.
